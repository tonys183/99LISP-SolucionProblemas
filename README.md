# 99 problemas de Lisp

Soluciones a ejercicios de [L-99: Ninety-Nine Lisp Problems](https://www.ic.unicamp.br/~meidanis/courses/problemas-lisp/L-99_Ninety-Nine_Lisp_Problems.html), desarrolladas en Scheme, Prolog y Erlang.

El repositorio reúne ejercicios de manejo de listas, recursividad, operaciones aritméticas y árboles, organizados en carpetas según el lenguaje utilizado:

- **Scheme:** carpeta `scheme/`.
- **Prolog:** carpeta `prolog/`.
- **Erlang:** carpeta `erlang/`.
